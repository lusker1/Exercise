# Java Methods Practice

A collection of Java exercises focusing on methods, modular code structure, and fundamental logic practice.

## Folder Contents

| File | Description |
| :--- | :--- |
| `LineDrawer.java` | Custom line drawing method using parameters. |
| `AverageMethod.java` | Basic math operations and average calculation. |
| `ScopeTest.java` | Testing variable scope within methods. |
| `MethodOverloading.java` | Practical examples of method overloading. |
| `JavaMethodsTraining.java` | Core methods logic and structure practice. |
| `LogicMethodsPractice.java` | Boolean logic and decision-making inside methods. |
| `MathOperations.java` | Built-in Math class methods and utility functions. |
| `SmallestNumber.java` | Finding the minimum value using custom methods. |
| `DistanceCalculator.java` | Calculating distance between 2D points using arrays. |
| `DayOfWeek.java` | Mapping numbers to days using switch statements. |
| `RandomRounder.java` | Random decimal generation and rounding functions. |
| `RandomCalculator.java` | Arithmetic calculations on random numbers (1-50). |

## Overview

Each file contains an independent solution covering specific concepts such as:
- Parameter passing and return values
- Array manipulation inside methods
- Random number generation with `Math.random()`
- Basic type casting and precision control
