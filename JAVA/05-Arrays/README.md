# ☕ Java Arrays & Methods Practice

Welcome to my Java programming practice repository! This repository focuses on implementing core programming concepts in Java, specifically practicing **Arrays** (1D and 2D) and writing reusable **Methods**. 

---

## 📂 Project Structure

Here is a breakdown of the files included in this repository:

*   **`2D-Arrays/`**: A dedicated folder containing exercises and practices focused on Two-Dimensional Arrays.
*   **`EmployeeSalaries.java`**: An interactive exercise implementing dynamic arrays to manage and calculate employee salaries.
*   **`JavaMethodsPractice.java`**: A comprehensive script showcasing fully interactive array operations leveraging modular Java methods.
*   **`MinMaxArrayFinder.java`**: An algorithmic exercise designed to find the largest (maximum) and smallest (minimum) elements within a user-defined array.
*   **`PositiveArray.java`**: A practice script focused on filtering, summing, and processing positive integers from an array.

---

## 🛠️ Concepts Covered

*   **Array Declaration & Initialization**: Declaring and instantiating 1D and 2D arrays with explicit and dynamic sizing.
*   **Method Implementations**: Writing clean, modular code by separating logic into reusable static methods.
*   **User Interaction**: Gathering user input using `Scanner` to dynamically populate array elements.
*   **Iterative Execution**: Leveraging nested loops and conditional statements to parse and process data sets.
